# Spatula Overlay

ปุ่มลอยบน Android ที่กางเป็นหน้าต่างดูคอมพ์ TFT ทับตัวเกม โดยไม่ต้องออกจากเกม

## ทำไมต้องมี

เกมเซฟคอมพ์ไว้ดูระหว่างเล่นได้แค่ 3 อัน และการเปิดดูในเกมก็ต้องหยุดเล่น
แอปนี้แก้ทั้งสองข้อ — ปักหมุดได้ไม่จำกัด และดูได้โดยเกมยังอยู่ตรงหน้า

## โครงสร้าง

```
MainActivity   ขออนุญาต "แสดงทับแอปอื่น" แล้วสั่งเริ่ม/หยุด — แค่นั้น
OverlayService ปุ่มลอย + หน้าต่าง WebView ที่กางออกมา
Config         URL ของสองโหมด
```

UI ทั้งหมดเป็นเว็บ ตัวแอปเป็นแค่เปลือก — แก้หน้าตาที่ repo ของเว็บ
ไม่ต้อง release แอปใหม่

## สองโหมด

| โหมด | ชี้ไปที่ | ได้อะไร |
|---|---|---|
| หมุดของฉัน | เว็บแอปของเรา | ปักหมุดไม่จำกัด ใช้ได้ออฟไลน์ ไม่ต้องล็อกอิน |
| ทั้งหมด | เว็บ official | ข้อมูลสดที่สุด มีข่าว/ไกด์ |

**การล็อกอินของเว็บ official วิ่งผ่าน SDK ของตัวเกม** (เห็นได้จาก `isInMSDK`
ใน URL ล็อกอินของเขา) เพราะงั้น WebView นอกเกมจะเปิดดูได้แต่เซฟไม่ได้ —
ซึ่งเป็นเหตุผลที่การปักหมุดต้องอยู่ฝั่งเรา และเก็บในเครื่องโดยไม่พึ่งบัญชีใคร

## รายละเอียดที่สำคัญ

**flag ของหน้าต่าง** คือหัวใจของการอยู่ร่วมกับเกม:

- `FLAG_NOT_TOUCH_MODAL` เปิดตลอด — นิ้วที่แตะนอกหน้าต่างเราต้องทะลุไปถึงเกม
  ไม่งั้นเกมจะเล่นไม่ได้เลย
- `FLAG_NOT_FOCUSABLE` เปิดตอนย่อ ปิดตอนกาง — หน้าต่างที่ไม่ focus จะรับ
  คีย์บอร์ดไม่ได้ ถ้าเปิดค้างไว้จะพิมพ์ค้นหาไม่ได้ ถ้าปิดค้างไว้จะไปแย่ง
  ปุ่ม back กับคีย์บอร์ดของเกม

**`domStorageEnabled` ต้องเปิด** ไม่งั้น localStorage ไม่ทำงาน = หมุดหายทุกครั้ง
ที่ปิดหน้าต่าง

**cookie ต้อง flush** ตอนปิด ไม่งั้น session ที่ล็อกอินไว้หายเมื่อปิดแอป

## Build

ต้องมี Android SDK (compileSdk 35) และ JDK 17+

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

ยังไม่มี `gradle-wrapper.jar` ใน repo — เปิดโปรเจคด้วย Android Studio
สักครั้งแล้วมันจะสร้างให้ หรือรัน `gradle wrapper` ถ้ามี gradle อยู่แล้ว
